# AI 广告素材生成平台 MVP

这是依据最终设计规格制作的第一版可交互前端原型。当前版本使用本地模拟数据，覆盖员工、管理员和代理商三类角色的主要页面与交互，不包含真实生成模型、审核中台或投放平台接口。

## 已实现模块

- 图片素材生成：AI 原创、爆款复刻、Agent 对话、结构化方案、商品管理、预览与批量生成
- 视频素材生成：创意结构、分镜脚本、组件配置、预览与批量生成
- 任务进度：生成/审核状态、任务详情、部分完成与异常恢复
- 审核管理：外部审核结果只读展示、驳回原因与修改入口
- 素材库：筛选、详情、追溯、授权、下载与批量导出
- 知识库：公共、图片和视频知识，版本与有效期
- 素材数据：生产效率、投放表现和 U1/U2/U3 维度明细
- 账号管理：员工申请、员工权限、代理商账号与下载记录
- 代理商门户：有效授权素材与下载记录

## 本地使用

```powershell
npm.cmd run dev
```

打开 `http://127.0.0.1:4173`。

## 验证

```powershell
npm.cmd test
npm.cmd run build
```

构建产物生成在 `dist` 目录。

## 当前边界

- 数据与操作结果均为前端演示状态，不会写入后端。
- 审核由外部审核中台完成，本平台只同步并展示状态。
- 原型中的图片为演示素材，不代表最终商用资产。
- 产品仍待确认的业务问题记录在项目资料中的待确认问题清单，当前实现不擅自固化这些规则。
